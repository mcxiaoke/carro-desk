# 变更记录

## 2026-10-02 22:09 — 缺陷与 UI/UX 修复（安全加固 / 国际化补齐 / 交互修正）

- **PIN 防暴力破解并发绕过（安全）**：
  - `PinGuard` 的失败计数与封锁时间此前完全无同步，而调用链天然并发
    （管道每连接独立 Task →`Task.Run` 执行handler），可让上百个并发请求
    同时读到相同的失败计数并互相覆盖，使「连错 5 次封锁」形同虚设；
  - 改为「锁内原子预留名额 → 锁外执行 PBKDF2 慢运算 → 锁内结算」，
    慢验证不阻塞计数，但也无法跳过计数，5 次上限重新可信。
- **IPC 限流可被绕过（安全）**：
  -限流键包含请求体里的 `source`，而该字段完全由调用方声明，
    每次换一个值即可让限流恒真，且限流字典条目数随调用量无界增长；
  - 协议解析层新增 `source` 白名单归一化（未知值折叠为 `unknown`），
    限流器另加容量上限与过期清理作为兜底。CLI/MCP 区分来源的语义与审计可读性均保留。
- **关闭自动静音后不恢复声音**：`OnConfigReloaded` 的禁用分支补上全量解除静音，
  消除「设置窗口关闭开关后进程持续静音到退出」的不对称行为。
- **DDC 亮度调节偶发永久失效**：异步应用任务体加 `finally` 兜底复位，
  并将单台显示器的硬件写入异常隔离在本轮内，避免一次瞬时 dxva2/WMI 异常
  使 `_isApplying` 永久为 true、此后所有请求都返回已 faulted 的 Task。
- **设置窗口国际化补齐**：
  - AppAutoMute / AudioSwitch / Awake / MonitorProfile 四个窗口此前
    `loc` 引用数为 0（其中三个连命名空间都未声明），切到 en-US 后仍整窗显示中文；
  - 另补 ClipboardHistorySettings、ClipboardHistoryWindow 标题、LockWindow
    提示与逃生按钮、TaskEditor 16 处局部硬编码；
  - 共新增 **153 组中英双语文案键**，XAML 全部采用
    `{loc:Loc Key, Default='原中文'}` 形式，缺键时回落原文，行为与改动前一致。
- **剪贴板历史右键删错条目**：右键菜单打开前把选中项同步到被右键行。
  此前菜单处理器读的是 `HistoryList.SelectedItem`，而筛选后选中会被重置为首行，
  导致右键 B 行却删掉列表第一条；右键删除另加二次确认（Delete 键路径保持一键删除）。
- **Esc 行为统一**：7 个缺失 `IsCancel` 的设置窗口补齐，
  消除「在 PIN 窗会Esc 取消、在设置窗毫无反应」的三套标准。
- **删除确认与空态提示**：
  - 删除显示器情境模式补二次确认（会连带清除该模式全部时间点，不可撤销），
    与同窗口「恢复默认」及 ScreenLock/AppAutoMute 的清空列表行为对齐；
  - 显示器时间点表格、AppAutoMute 受控列表补空态占位提示。
- **窗口最小尺寸**：`ConfigEditorWindow` / `ScreenLockSettingsWindow` /
  `TaskEditorWindow` 补 `MinWidth`/`MinHeight`，避免缩放到内容错乱。
- **测试修复**：`XamlLayout_AllGrids_HaveSufficientRowAndColumnDefinitions`
  原以固定层数上溯定位项目根，但测试输出含平台目录层（`bin\Any CPU\Debug\net48`），
  导致查找 `tests\src` 抛 `DirectoryNotFoundException`；
  改为按目录名逐级上溯匹配同时含 `src/` 与 `tests/` 的项目根，不再依赖输出深度。
- **验证**：全量单元测试 **300/300 100% 通过**，编译 **0 警告 0 错误**。
- **按影响面搁置**（改动面大、易引入新问题，未在本次处理）：
  剪贴板敏感内容过滤、锁屏鼠标穿透拦截、混合DPI 下锁屏定位、
  手动调亮度被时间表覆盖、detach 任务 stdout 阻塞、全部窗口脏检查。

## 2026-10-02 19:50 —剪贴板历史新增「展开全文」独立详情窗口

- **新增全文详情窗口** `ClipboardItemDetailWindow`：
  - 替换原先的 `MessageBox.Show` 展示方式（MessageBox 不可滚动、不可选区、无法复制长文本）；
  - 窗口内以只读多行文本框承载完整内容，支持鼠标拖选、`Ctrl+A` 全选、`Ctrl+C` 复制、双向滚动；
  - 打开即自动聚焦并全选，可直接 `Ctrl+C` 取走全文，也可取消选择后局部复制；
  - 顶部展示元信息（字符数、行数、复制时间、置顶标识），底部提供「自动换行」开关与「全选 / 复制全文 / 复制并粘贴 / 关闭」按钮。
- **可靠性设计**：
  - 回写剪贴板后调用 `SuppressNext` 抑制监听器自环录入，避免条目被重复记录；
  - 「复制并粘贴」严格限定粘贴回打开浮窗前记录的原目标窗口 HWND，防止误贴到其它应用；
  - 写剪贴板失败时中止后续关闭与模拟粘贴动作，杜绝把剪贴板旧内容误发；
  - 超过 20 万字符的文本仅在显示层截断并给出提示，「复制」仍为完整原文，避免超大文本卡死 UI。
- **入口与生命周期**：
  - 新增三种打开方式：行内 `⤢` 按钮、右键「查看完整内容...」、列表内 `V` 快捷键；
  - 详情窗口全局单例复用，重复打开只换内容并前置，不会刷出多个窗口；
  - 打开详情时自动隐藏失焦即隐的浮窗，关闭详情后浮窗回归，且不重新采集粘贴目标以保持原目标句柄有效；
  - 浮窗关闭（模块停止）时同步关闭详情窗口，杜绝残留幽灵窗口。
- **本地化**：新增 14 个中英双语文案键，两语言 key 集合与占位符保持一致。
- **单元测试**：新增详情窗口渲染快照测试与「保留完整原文 + 元信息正确」行为测试；全量单元测试 **300/300 100% 全部通过**。
