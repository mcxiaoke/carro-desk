# 变更记录

## 2026-10-02 19:50 — 剪贴板历史新增「展开全文」独立详情窗口

- **新增全文详情窗口** `ClipboardItemDetailWindow`：
  - 替换原先的 `MessageBox.Show` 展示方式（MessageBox 不可滚动、不可选区、无法复制长文本）；
  - 窗口内以只读多行文本框承载完整内容，支持鼠标拖选、`Ctrl+A` 全选、`Ctrl+C` 复制、双向滚动；
  - 打开即自动聚焦并全选，可直接 `Ctrl+C` 取走全文，也可取消选择后局部复制；
  - 顶部展示元信息（字符数、行数、复制时间、置顶标识），底部提供「自动换行」开关与「全选 / 复制全文 / 复制并粘贴 / 关闭」按钮。
- **可靠性设计**：
  - 回写剪贴板后调用 `SuppressNext` 抑制监听器自环录入，避免条目被重复记录；
  - 「复制并粘贴」严格限定粘贴回打开浮窗前记录的原目标窗口 HWND，防止误贴到其它应用；
  - 写剪贴板失败时中止后续关闭与模拟粘贴动作，杜绝把剪贴板旧内容误发；
  - 超过 20 万字符的文本仅在显示层截断并给出提示，「复制」仍为完整原文，避免超大文本卡死 UI。
- **入口与生命周期**：
  - 新增三种打开方式：行内 `⤢` 按钮、右键「查看完整内容...」、列表内 `V` 快捷键；
  - 详情窗口全局单例复用，重复打开只换内容并前置，不会刷出多个窗口；
  - 打开详情时自动隐藏失焦即隐的浮窗，关闭详情后浮窗回归，且不重新采集粘贴目标以保持原目标句柄有效；
  - 浮窗关闭（模块停止）时同步关闭详情窗口，杜绝残留幽灵窗口。
- **本地化**：新增 14 个中英双语文案键，两语言 key 集合与占位符保持一致。
- **单元测试**：新增详情窗口渲染快照测试与「保留完整原文 + 元信息正确」行为测试；全量单元测试 **300/300 100% 全部通过**。
