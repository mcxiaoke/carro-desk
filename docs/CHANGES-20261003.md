# 变更记录

## 2026-10-03 09:40 — NSIS 安装包与一键升级（免手动结束进程）

- **新增 NSIS per-user 安装包**（`scripts/installer/CarroDesk.nsi`）：
  - 默认安装到 `%LOCALAPPDATA%\Programs\CarroDesk`，`RequestExecutionLevel user` 全程不弹 UAC；卸载项写 `HKCU`，与程序自启（`HKCU\...\Run`）同一用户上下文。
  - **自动结束进程**：安装/升级/卸载前用 `taskkill /F /T` 结束 `CarroDesk.exe` 与 `CarroDesk.Cli.exe`（含子进程树），解决此前"复制便携版覆盖需手动杀主进程与 CLI 进程"的问题；检测到进程在运行时先弹窗确认。
  - **数据模式单选页**（nsDialogs 自定义页）：漫游模式（`%AppData%\CarroDesk`）/ 便携模式（安装目录 `app_data`，写入 `portable.ini`，行为与绿色版一致）；检测到旧安装时默认沿用其模式，切换模式且目标无配置时自动迁移数据，不删除任何数据。
  - 升级只覆盖 exe / 配置文件，样例文件仅在缺失时写入；卸载移除程序文件与快捷方式，配置与任务数据默认保留并提示；仅当自启项指向本安装目录时才删除该注册表值。
  - 简体中文 + 英文双语言表，LZMA 固态压缩，安装包约 1.5 MB。
- **`scripts/release.py` 集成安装包构建**：
  - 新增 `build_setup()`，按 `makensis`（PATH → Scoop → Program Files 顺序探测）编译 `CarroDesk-<version>-setup.exe`；未安装 NSIS 时给出明确提示并跳过，不影响 zip 便携包。
  - 新增 `--no-setup` / `--setup-only` / `--help` 参数；`write_sha256()` 校验范围扩展到 `*.exe`。
  - 新增 `ensure_utf8_bom()`：makensis 以系统 ANSI 代码页读取脚本，自动补 UTF-8 BOM 防止中文乱码编译失败。

## 2026-10-03 09:07 — 物理内存裁剪与工作集优化 (Memory Trimming)

- **物理内存常驻占用过高优化**：
  - 新增 `MemoryOptimizer` 内存优化器，封装托管堆垃圾回收（Gen2 强制收集与终结器释放）与 Win32 `SetProcessWorkingSetSize(-1, -1)` 物理工作集修剪机制。
  - 内置线程安全防抖与节流保护（最小触发间隔 30 秒），统一在后台线程异步执行，绝不阻塞 UI 消息泵，防止频繁触发引起页面软缺页颠簸。
  - **启动后自动修剪**：宿主冷启动完成 8 秒后自动执行一次后台深度修剪，将 JIT 编译、程序集解压及 XAML 解析期间触碰的 140MB+ 临时冷数据彻底释放给操作系统。
  - **浮动面板关闭后修剪**：`FloatingPanelWindow` 隐藏时排队 2 秒延迟修剪，及时回收面板渲染产生的临时视觉树与资源。
  - **空闲期自动维护**：系统空闲超过 5 分钟且工作集超过 50MB 时平滑执行修剪维护。
  - 新增 `MemoryOptimizerTests` 4 项单元测试，验证节流防抖、阈值判定与异步调度稳定性；全量 304 项单元测试均通过。
