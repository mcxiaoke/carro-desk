# 变更记录 2026-11-25

## 2026-11-25 10:03:41 — fix(modules,views): 修复业务模块并发状态与视图生命周期/DPI 缺陷

- **AppAutoMute & AudioSwitch**：
  - `AppAutoMuteModule`：黑名单双目标直切同步启动 `_muteTimer` 静音后台旧目标；`OnStart` 失败回滚时 `OnStop` 判空 `_foregroundTracker`；`OnConfigReloaded` 重载前按旧配置恢复静音；设置窗口滑块开启 50ms 步进对齐。
  - `AudioSwitchSettingsWindow`：`_offlineExclusions` 仅保留真正未匹配在线设备的条目，并在清除排除/恢复默认时同步清空；`OnTestToggleClick` 不再污染未保存的 `_module.Config`。`AudioSwitchModule.OnConfigReloaded` 补充托盘刷新，图标匹配增加英文兜底。
- **ScreenLock & MonitorProfile**：
  - `IpPresenceDetector`：移除首次同步阻塞探测，全路径异步探测并增加 `_generation` 防 `Reset` 竞态。
  - `LockWindow` & `LockController`：`WINDOWPOS.flags` 修正为 32 位 `uint` 并更新对应契约测试；关闭窗口时停止兜底定时器并移除 `HwndSource` 钩子；`Dispose` 同步等待解锁后再卸载键盘钩子；`ScreenLockModule` 重载刷新托盘且设置窗防重入。
  - `MonitorProfileModule` & `ProfileScheduleEngine`：热键与引擎公开操作校验 `Enabled` 状态，重载后刷新托盘；`MonitorDdcService` 修复合并写入计数错位并即时捕获 Win32 错误码；设置窗校验时间点防重。
- **Awake、ClipboardHistory、ServiceControl 与 Views**：
  - `AwakeService`：引入 `_stateLock` 保护跨线程读写，支持 IPC 调用 `updateConfig: false` 不污染持久化配置；`AwakeModule` 使用 `CustomPresets`；`AwakeSettingsWindow` 校验热键与数字范围并在选 `Passive` 时停止活跃进程联动。
  - `ClipboardHistoryModule`、`Win32ClipboardListener`、`ClipboardHistoryService`、`ClipboardHistoryWindow`：禁用态不注册热键、`OnStop` 用 `try/finally` 确保 `FlushStorage`、监听器绑定 UI `Dispatcher`、`ConsumeSelfEcho` 的 `_suppressedHash` 声明 `volatile`、删除确认框传入 `Owner` 并保护 `_isModalOpen`。
  - `WindowsServiceControlAdapter`：区分无权限（抛出由上层记为 `"Unknown"`）与服务不存在（`"NotFound"`）。
  - `FloatingPanelWindow`：拦截非退出关闭改为隐藏、`OnClosed` 解绑语言事件、高 DPI 下 `Custom` 定位按 `VisualTreeHelper.GetDpi` 缩放至 DIP；`ConfigEditorWindow` 复制诊断信息传 `copy: true`；`AboutWindow` 关闭停 `_toastTimer`；`VerifyPinWindow` 补全锁定倒计时提示；抽离通用 `InputPromptDialog` 消除三处重复输入弹窗。
- **验证**：548 项单元测试全部通过（新增 3 项），Release 构建 0 警告 0 错误。

## 2026-11-25 09:54:08 — fix(tasks): 修复 TaskScheduler 触发器、状态机竞态与句柄/定时器泄漏

- **触发器调度修复**：
  - `DailyTrigger`：跨天启动/重载时若已过当日触发点且昨日曾运行，不再绕过 `catchUpMissed=false` 立即补跑；移除 `Start()` 中的立即补触发逻辑。
  - `IntervalTrigger`：状态仓库同步记录 `interval:sec`，配置变更间隔后重算下次触发时间；`RunAtStartup` 派发时同步顺延定时间隔，避免 1ms 后双发。
  - `StartupTrigger`：超过 49.7 天延迟时分段 `Task.Delay`，记录异常日志；`FileWatcherTrigger`：修复单文件目标父目录缺失时的误建目录问题及启动失败清理；`IdleTrigger`：经服务层会话标记避免长空闲期配置重载重复触发。
- **状态机与并发竞态修复**：
  - `TaskSchedulerService.ExecuteAsync`：消除 `slot.StopRequested` 与 `finally` 的双重 `OnProcessExited`，并以 `startedProcess` 区分未启动放弃与真实退出。
  - `TaskSchedulerService` & `TaskStateMachine`：为 `OnStopCompleted` 增加 `onlyIfStopping` 守卫防止异步杀进程覆写新实例状态；`ApplyCoreLocked` 重载时保留仍有效的 `WaitingRetry` 守护槽并保持其状态机一致，`RestartContinue` 读取最新 `TaskDefinition`；将 `TaskFireLimiter` 限流扣减后移至条件与占槽通过之后；`SetGlobalEnabled`/`Reload` 纳入 `_applyLock` 与 Dispatcher 串行化；`OnPowerModeChanged` 锁外执行 `CheckCatchUp`。
  - `TaskProcessHandle`：`Dispose()` 唤醒挂起的 `WaitForExitAsync` 并确保未进入 `WaitAsync` 的 `RunContext`/`RunLogWriter` 定时器安全关闭；`AttachDetached` 提前停止分支补全 `Dispose()`；`KillTree` 直接调用 `taskkill.exe`。
- **配置与 UI 边界修复**：
  - `TaskDefinition.ParseDuration` 增加溢出检查；`TaskConfigService` 修复纯注释 `tasks.json` 误判损坏及 `every`/`everySec` 序列化一致性；`TaskRunner` 调整工作目录解析至模板展开之后并传递 `attempt`。
  - `TaskManagerWindow` 修复采样代际清零竞态、保存失败前不提前修改内存列表及 `_scheduler` 空值校验；`TaskEditDialog` 补全控制台编码选项与别名映射、Cron 语法错误区分及 `detach` 测试自然退出监视。
- **验证**：545 项单元测试全部通过（新增 4 项），Release 构建 0 警告 0 错误。
