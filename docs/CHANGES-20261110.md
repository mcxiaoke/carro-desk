## 2026-11-10 13:07:10 — fix(tasks): 调度状态机与停止/重载时序修复（OPEN-ISSUES 批次1 · S1/H4/H3/H2/H1）

- S1 重试计数：新增 `TaskStateMachine.OnAttemptStarted`，同一次执行内的重试只更新 pid、不再重复 `ActiveInstances++`；此前每轮重试加一次而 `finally` 只减一次，任务重试后永久"假运行"。
- H4 WaitingRetry 卡死：`OnAbandon()` 对 WaitingRetry 归位 Idle 并取消倒计时（保留失败预算）；`Reset()` 同样处理 WaitingRetry；`RestartContinue` 的"槽已释放"与异常分支补 `OnAbandon`。
- H3 重启时序：`TaskProcessHandle.Stop` 在释放单实例互斥体前等待进程真正退出（≤3s）；新增 `TaskProcessHandle.WaitForExit(TimeSpan)`；`TryStop` 抽出 `StopInternal` 并新增 `StopAndWaitAsync`，`RestartTask` 删除固定 300ms，改为等待旧实例终结后再启动，超时则取消重启并提示（新增 `Tasks.RestartTimeout` 中英键）。
- H2 重载停旧实例：`ApplyCoreLocked` 计算新配置的启用任务名集合，对已删除/禁用任务的全部运行槽置 `StopRequested`、出册并在后台终止进程树；同名仍启用的任务不受影响（保持守护链）。
- H1 补跑重复：新增 `_lastDailyFire`（任务名→日期），`OnTriggerFired` 记录 `daily:` 触发；`CatchUpMissed` 判断同时参考它，当天已正常执行过的任务配置重载后不再补跑。
- 测试：`TaskStateMachineTests` 新增重试不累加实例、WaitingRetry 放弃/重置归位 3 例；`TaskPersistentRunTests` 新增"重载删除任务即停实例"1 例。
- 验证：`dotnet build` 0 警告 0 错误；`dotnet test` **426 通过 / 0 失败 / 0 跳过**。
