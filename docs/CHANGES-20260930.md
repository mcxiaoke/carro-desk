# 变更记录

## 2026-09-30 15:25 — 显示器熄屏休眠感知跳过 + 唤醒亮屏延迟 3 秒自愈补偿 + DDC/WMI 降噪

- **显示器电源事件感知与休眠跳过**：
  - 新增 `IDisplayPowerListener` 与 `DisplayPowerListener`，基于 Windows 原生 `RegisterPowerSettingNotification` 监听控制台显示器状态（`GUID_CONSOLE_DISPLAY_STATE`）与显示器电源（`GUID_MONITOR_POWER_ON`），零轮询捕获亮屏、熄屏与休眠；
  - `ProfileScheduleEngine` 定时器与应用入口增加 `IsDisplayOn` 状态检测：显示器熄灭或休眠时，主动跳过定时调节与 DDC/WMI 硬件通信，彻底解决熄屏时的死循环重试与硬件总线错误。
- **亮屏延迟 3 秒自愈补偿**：
  - 显示器点亮开启或系统解锁唤醒时，自动启动 3 秒延迟自愈防抖计时器（带 `CancellationTokenSource` 冲突取消），等待显示器完成 DP/HDMI 硬件链路握手后，自动重新应用当前时间段的情境亮度与对比度。
- **DDC 休眠错误识别与 WMI 探活降噪**：
  - `MonitorDdcService` 增加对 Win32 错误 `-1071241847`（`0xC0262589`，`STATUS_GRAPHICS_I2C_ERROR_TRANSMITTING_DATA`）及接收错误（`0xC026258A`）的识别，识别为休眠/未就绪状态并降为 Debug 级别，杜绝控制台错误日志刷屏；
  - 发生显示器休眠通信错误时，阻断向不支持外接显示器的 WMI 进行盲目回退；
  - `SetBrightnessViaWmi` 与 `GetBrightnessViaWmi` 增加 `_wmiSupported` 探活缓存，捕获外接屏幕或驱动不支持异常后自动禁用后续无效尝试，杜绝 `ManagementException: 不支持` 异常刷屏。
- **单元测试**：新增显示器休眠错误码识别测试、息屏硬件调用短路测试与监听生命周期测试；全量单元测试 **298/298 100% 全部通过**。

## 2026-09-30 12:50 — 屏幕保护增强：暂停预设扩充 + 自动锁屏开关 + IP设备在线免锁（移植自 Carrot.AutoLock）

- **暂停计时预设扩充**：托盘“暂停计时”二级菜单项改为 `[30分钟, 1小时, 2小时, 4小时, 8小时]` 预设，自定义暂停分钟数默认值调整为 30。
- **自动锁屏开关**：
  - `ScreenLockConfig` 增加 `AutoLockEnabled`（默认 true），关闭后闲时不会触发自动锁屏，但不影响热键（如 Ctrl+Alt+L）和托盘“立即锁定”；
  - 托盘“空闲锁定”二级菜单首项增加 `[x] 启用自动锁定` 切换项；
  - 设置窗口增加 `[x] 启用闲时自动锁定` 勾选框，联动禁用/启用空闲时长下拉框。
- **IP 设备在线免锁屏（移植自 Carrot.AutoLock）**：
  - 纯原生 .NET 4.8 架构，零 WinRT / 零第三方依赖：采用 `Ping` + Windows 原生 `iphlpapi.dll` 的 `SendARP` 双重探测，兼顾亮屏极速响应与黑屏休眠链路层穿透；
  - 新增 `IpPresenceDetector` 服务，内置 10s 探测缓存与离线防抖缓冲（默认 30s），接入 `ScreenLockModule.ShouldSuspendIdle()`；
  - 设置窗口增加【设备感知免锁（近场免打扰）】配置卡片，支持配置目标 IP、离线缓冲秒数，并提供异步【测试连接】按钮与状态提示。
- **本地化与测试**：补齐中英文语言包（zh-CN/en-US）所有新键；新增 `DevicePresenceAndAutoLockTests`（4项）；全量单元测试 **295/295 100% 通过**，0 错误 0 警告。
- **架构文档**：新建 `docs/SCREENLOCK-DEVICE-PRESENCE-AND-PAUSE-DESIGN-20260930.md`。
