# 变更记录

## 2026-09-30 12:50 — 屏幕保护增强：暂停预设扩充 + 自动锁屏开关 + IP设备在线免锁（移植自 Carrot.AutoLock）

- **暂停计时预设扩充**：托盘“暂停计时”二级菜单项改为 `[30分钟, 1小时, 2小时, 4小时, 8小时]` 预设，自定义暂停分钟数默认值调整为 30。
- **自动锁屏开关**：
  - `ScreenLockConfig` 增加 `AutoLockEnabled`（默认 true），关闭后闲时不会触发自动锁屏，但不影响热键（如 Ctrl+Alt+L）和托盘“立即锁定”；
  - 托盘“空闲锁定”二级菜单首项增加 `[x] 启用自动锁定` 切换项；
  - 设置窗口增加 `[x] 启用闲时自动锁定` 勾选框，联动禁用/启用空闲时长下拉框。
- **IP 设备在线免锁屏（移植自 Carrot.AutoLock）**：
  - 纯原生 .NET 4.8 架构，零 WinRT / 零第三方依赖：采用 `Ping` + Windows 原生 `iphlpapi.dll` 的 `SendARP` 双重探测，兼顾亮屏极速响应与黑屏休眠链路层穿透；
  - 新增 `IpPresenceDetector` 服务，内置 10s 探测缓存与离线防抖缓冲（默认 30s），接入 `ScreenLockModule.ShouldSuspendIdle()`；
  - 设置窗口增加【设备感知免锁（近场免打扰）】配置卡片，支持配置目标 IP、离线缓冲秒数，并提供异步【测试连接】按钮与状态提示。
- **本地化与测试**：补齐中英文语言包（zh-CN/en-US）所有新键；新增 `DevicePresenceAndAutoLockTests`（4项）；全量单元测试 **295/295 100% 通过**，0 错误 0 警告。
- **架构文档**：新建 `docs/SCREENLOCK-DEVICE-PRESENCE-AND-PAUSE-DESIGN-20260930.md`。
