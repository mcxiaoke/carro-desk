# 2026-10-14 变更记录

## 10:57:15 剪贴板历史新增敏感信息过滤（关键词命中即不保存）

- 新增 `ClipboardFilterRule`（Pattern / IgnoreCase / Enabled）与 `ClipboardTextFilter` 不可变规则集：字面包含匹配（`IndexOf` + Ordinal 族比较），空关键字与停用规则在构造期剔除；规则集随配置重建、运行期复用。
- `ClipboardHistoryConfig` 新增 `FilterEnabled`（默认 **关闭**）、`FilterRules`；`Clone()` 由浅拷贝改为深拷贝（设置窗口依赖它做保存失败回滚）。
- `ClipboardHistoryService.RecordText` 接入过滤：位于开关检查之后、`MaxTextLength` 截断**之前**（避免关键字落在被截掉尾部而漏检）；命中即整条丢弃，不入内存、不落盘、不触发 `HistoryChanged`，不回溯清理历史中已有条目。新增 `ContentFiltered(rule, textLength)` 事件——只带规则与字符数，不带原文。
- 模块层订阅该事件记日志并按规则 30 秒限流；托盘 `剪贴板历史` 新增「敏感信息过滤（命中即不保存）」勾选开关与「敏感信息过滤设置...」入口，开关保存失败回滚内存态并刷新托盘。
- 新增独立窗口 `ClipboardFilterSettingsWindow`（规则增删改、启用开关、忽略大小写；校验非空/长度 ≤256/条数 ≤200/重复）；编辑期间只改本地副本，保存成功走 `OnConfigReloaded()`，失败按 `Clone()` 快照回滚。历史设置窗口与历史浮窗未改动。
- 语言包 `zh-CN.json` / `en-US.json` 同步新增 17 个 `Clipboard.Filter*` 文案；`config.sample.json` 与 `docs/USAGE.md` 补充说明。
- 新增 `tests/CargoDesk.Tests/ClipboardFilterTests.cs`（16 个用例，含托盘入口与窗口实例化）并登记进 csproj。全量 `dotnet test`：**391 通过 / 0 失败**。
- 设计文档：`docs/CLIPBOARD-SENSITIVE-FILTER-DESIGN-20261014.md`。
