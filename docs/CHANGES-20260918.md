  - **多工作模式与屏幕分离控制**：
    - 支持 4 种工作模式：关闭（遵循系统默认电源策略）、无限期保持唤醒、定时倒计时保持唤醒（内置 15m/30m/1h/2h/4h/8h 快捷预设）、保持唤醒至指定时刻（如 18:00 下班前）；
    - 屏幕常亮与系统唤醒精细分离：支持勾选“保持屏幕常亮”（系统+屏幕全开，适合看文档与演示）或取消勾选（仅阻止系统休眠，允许显示器按时熄灭省电，对 OLED 友好）。
  - **智能环境感知与电池保护**：
    - **笔记本电池保护**：断开交流电使用电池或电量低于预设阈值（默认 20%）时自动暂停保持唤醒并弹窗通知，防止放包内发热或意外耗尽电量；重接电源自动恢复；
    - **目标进程联动**：支持配置进程名单（如 devenv, blender, ffmpeg 等），检测到运行时自动进入保持唤醒，全部退出后自动恢复关闭。
  - **交互与生态协同**：
    - 遵循 CarroDesk 二级收敛规范，根项动态显示当前状态与剩余时间，同时自动无缝集成于桌面控制面板（FloatingPanel）；
    - 支持全局快捷键（默认 `Win+Shift+W`）一键快速切换，倒计时结束/低电量触发提供桌面气泡通知；
    - 提供专用现代卡片式配置窗口 `AwakeSettingsWindow`，支持运行中进程一键拾取与自定义时间输入。
