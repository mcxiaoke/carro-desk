## 2026-10-25 20:03:14 — fix(awake): correct privilege name and surface sleep failures (Batch 2, S4)

## 2026-10-25 20:00:32 — fix(pin): stale pending credentials and digits-only PIN (Batch 1, S1+S2)

代码审查报告 S1+S2 修复（PIN 凭据链路）：

- **S1** `HostPinService.VerifyCore` 新增 stale pending 检测：配置持有有效凭据且与 pending 不一致时丢弃 pending、以配置为准。修复"首次运行向导设置过 PIN 后，经配置编辑器修改 PIN，宿主重启前新 PIN 验证失败、旧 PIN 继续有效"（锁屏/退出确认/IPC 全部命中）。配置无有效凭据（SetNewPin 未落盘窗口期）时仍保留 pending，不破坏既有 P2-4 行为。
- **S2** `FirstRunWindow` PIN 设置限定纯数字（提取静态 `ValidatePin` 供校验与单测）：锁屏期间低级键盘钩子只放行数字，含字母/符号的 PIN 会导致锁屏后无法输入、永久锁死。语言包 zh-CN/en-US 新增 `FirstRun.ErrorDigitsOnly`，输入提示同步标注"数字"。
- 新增回归测试 `PinCredentialTests`（5 项：pending 一致路径、配置外部更换后新旧 PIN 语义、纯数字校验、语言包 key 存在）；`CarroDesk.Tests.csproj` 显式注册。
- 验证：`dotnet build` 0 警告 0 错误；`dotnet test` 396 通过 / 0 失败（基线 391 + 新增 5）。

存量提醒：已在旧版本设置含字母 PIN 的用户，升级后需通过配置编辑器重新设置纯数字 PIN（配置编辑器修改路径不受锁屏钩子限制）。
