## 09:45:47 单实例互斥机制重构与进程入口优化

- **单实例互斥与数据隔离**：
  - 弃用硬编码常量 `Global\CarroDesk_SingleInstance_2C7A4F10`，改为基于当前生效数据目录（`ConfigService.DirPath`）的确定性 SHA256 派生哈希命名：`Local\CarroDesk_{DataDirHash}` 与 `CarroDesk_Activate_{DataDirHash}`；
  - 完美兼容**普通漫游模式**（全系统同用户数据目录一致，单实例互斥）、**便携模式**（不同安装目录独立互斥与运行，相同目录严格互斥并定向唤醒）以及**测试环境**（`DataDirOverride = TempRoot`，测试与生产实例完全隔离）；
  - 命名空间由 `Global\` 收敛为 `Local\`，符合 Windows 会话隔离规范并消除低权限环境下的访问受限隐患。
- **独立入口 Program.cs 顶层重构**：
  - 新增 `src/Program.cs` 作为 `StartupObject` 入口，将 CLI / MCP / 二实例拦截时机前置到加载 WPF 核心框架与 XAML 资源之前；
