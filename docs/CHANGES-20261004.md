## 2026-10-04 11:25 — 代码审查问题整改（依据 docs/CODE-REVIEW-20261003.md，第二轮修复第一批：锁屏安全边界）

按"改动小、收益大、风险低"排序分模块落实，每批均编译（0 警告 0 错误）并跑全量单测。

### 严重（锁屏认证可绕过）

- **托盘绕过（R1）**：锁屏处于锁定态时，`ScreenLockModule.GetTrayMenuItems()` 不再输出任何菜单项。锁屏把"忘记 PIN"的风险转移给用户，不能同时留一条无需凭据的解除路径——原先可经托盘打开锁屏设置 → 关掉"启用"并保存 → `OnConfigReloaded` 执行 `Controller.Unlock()`。
- **设置窗口纵深防御（R1）**：`ScreenLockSettingsWindow` 新增由模块注入的锁定态探测，锁定期间拒绝保存；托盘点击设置入口处再拦一次，防止菜单构建后恰好发生自动锁定的竞态。
- **会话解锁免 PIN（R2）**：`UnlockOnResume` 默认值由 `true` 改为 `false`（含历史扁平字段迁移的兜底默认值与示例配置）。该路径不校验 PIN，默认开启等于"设了 PIN 也能被任何一次 Windows 会话解锁绕过"。
- **解锁留痕（R2）**：因 `UnlockOnResume` 自动解除锁屏时写审计日志，便于事后分辨锁屏被解除的来源。

### 文案

- `Config.UnlockOnResumeLabel/Desc` 改为明确标注"不校验 PIN / 跳过 PIN 校验"；新增 `Lock.SettingsBlockedWhileLocked`（zh/en）。

### 测试

- 新增 `ScreenLockSecurityTests`（4 例）：`UnlockOnResume` 默认值与 Clone 保留、设置窗口锁定守卫（含探测抛异常的兜底）、未锁定时托盘菜单不被误伤。

> 锁屏本身的真机锁定路径（全局键盘钩子 + 覆盖真实显示器的置顶窗口）刻意不在自动化测试内触发，仅断言锁定态判定所依赖的接缝。

## 2026-10-03 22:53 — 代码审查问题整改（依据 docs/CODE-REVIEW-20261003.md，第一批）

按"改动小、收益大、风险低"排序分模块落实，每批均编译（0 警告 0 错误）并跑全量单测。

**严重（数据丢失 / 隐私）**
- i18n 重载陷阱：`Loc.T(key, stringArg)` 因命中 `T(string,string)` 重载而不替换 `{0}`、吞掉异常详情；修正任务编辑器/屏锁设置/锁屏窗口/配置编辑器共 30 余处调用点为三参写法。
- 任务编辑器保存静默丢字段：编辑既有任务时保留 UI 未暴露的 `singleInstance`/`stableUptimeSec`；"复制任务"补齐 detach/restart 等全部选项字段。
- 剪贴板隐私：读取剪贴板时遵循 Windows 排除格式（`ExcludeClipboardContentFromMonitorProcessing`/`CanIncludeInClipboardHistory`/`CanUploadToCloudClipboard`），命中即不记录；新增 `MaxTextLength`（默认 100 万字符）限制单条长度。

**高危（安全 / 功能失效）**
- 锁屏 `LockSafe()` 改为同步封送，非 UI 线程下不再把"锁定失败"误报为成功。
- 任务 wait 模式"停止任务"不再被判为失败、不再触发重试/守护重启。
- PIN 校验串行化：消除并发请求下共享状态的读写撕裂。
- 悬浮面板菜单区加 `ScrollViewer` 并限高，模块增多时底部菜单不再移出屏幕。

**中危（健壮性 / 正确性）**
- Cron 正常到点不再被误标为 `cron-catchup`；配置内容损坏回退默认配置时新增告警弹窗（新增 zh/en 文案）。
- 能力注册表改为原子重建（失败保留原有效表）；`int` 参数遇 JSON 小数按整数语义收敛、非整数明确报错。
- `log.txt` 超 1MB 轮转；空闲服务"用户活跃"改为真正的边沿触发。
- CLI `ctl` 与父控制台回显统一 UTF-8；服务控制兼容访问被拒并对 `services.status` 逐服务隔离；过渡态给出明确错误。
- 剪贴板/显示器设置窗口统一校验热键；显示器时间表 DataGrid 改为只读；DDC 的 WMI 回退改为 30 秒冷却重试。
- Awake 仅在进程联动"关→开"时清除用户抑制；任务全局开关回滚不再递归持久化；`killWithHost` 挂接失败按用户意图走兜底并告警。

**其他**
- `src/Host/Ipc/RpcProtocol.cs` 由 GBK 转 UTF-8，符合仓库编码规范。
- 测试：修正恒真断言与名不副实用例名、补齐语言状态兜底清理；新增 3 个回归用例（能力表原子重建、int 参数收敛、非整数拒绝）。

**仍未处理（需真机/多屏环境验证，见审查报告第十节）**：多显示器 DPI 单位统一（M19）、悬浮面板副屏定位（M24）、Awake 睡眠权限（M15）、AppAutoMute 白名单轮询（M16）、任务并发实例治理（M6/M7）等。
