## 2026-09-28 15:00 — 实施 IPC 设计 S1+S2：命令内核 + 命名管道控制通道

- **S1 命令内核**（`src/Core/Commands/`、`src/Host/Commands/`）：`CommandRisk/CommandParam/CommandDescriptor/CommandRequest/CommandResult/ICommandProvider` 契约；`CommandRegistry`（白名单本体，大小写不敏感唯一）；`CommandHost`（分发器，校验顺序不可调换：存在性 -32601 → 模块 Running -32001 → 参数 -32602 → 口令 -32002 → 限流 -32003 → 执行超时 -32004/内部 -32010，异常绝不逃逸）；`CommandRateLimiter`（能力+来源维度固定窗口，时钟可注入）；`CommandAudit`（单行 JSON 落 `ipc-audit.log`，超 1MB 轮转，参数只记 SHA-256 摘要，口令原文绝不落盘）。`ModuleManager` 新增 `CollectCommands()`/`GetModuleStatus()`（pull 收集，逐模块异常隔离）；`App` 启动时装配并注册单例。内核只认原始 CLR 类型参数； RequiresPin 能力经 `PinGuard` 校验（复用宿主失败限流），口令由请求内联携带（v1.2「口令即确认」），无 PinGuard 时 fail closed。
- **S2 命名管道传输**（`src/Host/Ipc/`）：`FrameCodec`（[int32 LE][UTF-8 JSON]，1MB 上限，超限断开）；`RpcProtocol`（JSON-RPC 2.0 映射，`pin`/`source` 为协议扩展字段且不进参数摘要）；`NamedPipeCommandServer`（`PipeSecurity` 仅授当前用户 SID + SYSTEM；accept 循环 + 每连接独立任务；管道名带用户 SID）。`host.hello/host.status/host.modules.list/host.capabilities.list` 四个宿主能力（含能力表哈希，供客户端缓存）。`AppSettings` 新增 `Ipc { Enabled, PipeName, AuditEnabled }` 节，`CopyTo`/`Merge` 同步深拷贝（附回归测试）。
- **修复实测死锁**：`NamedPipeServerStream` in/out 缓冲区传 0（系统默认）时，「客户端流水线连发请求 + 服务端同时回写响应」双向写阻塞死锁——单请求逐次收发测不出来，keep-alive 端到端测试（blame-hang 定位）+ 控制台复现程序确认根因；改为显式 64KB 缓冲，坑已记录设计文档 §5.1 并固化为回归测试。
- **测试**：新增 `CommandHostTests.cs`（25 项：白名单/参数校验/Running 检查/超时/异常不逃逸/口令门/失败封锁/限流/审计脱敏/轮转）与 `IpcPipeTests.cs`（14 项：帧编解码/RPC 映射/配置深拷贝/真实管道端到端含口令与 keep-alive），已登记 `CarroDesk.Tests.csproj`。全量 **234/234 通过**，Debug+Release 构建 0 警告 0 错误。

## 2026-09-26 12:55 — 新增开发机远程管理通道脚本集（RDP / WinRM / SSH / SYSTEM Agent）

- **背景**：人不在电脑边时无法以管理员权限远程执行命令（启动服务等），UU远程客户端又启动即崩。实测确认：RDP 未开（`fDenyTSConnections=1`）、WinRM 未启用、UAC 提示在安全桌面（脚本无法代点），故需一次性管理员初始化。
- **新增（`docs/remote-admin/`，不参与项目构建）**：`setup-remote-access.ps1`（自提权、幂等、四通道可单开可全开，记录原始状态到 `C:\ProgramData\RemoteAdmin\state.json`）；`remote-admin-agent.ps1`（以 SYSTEM 运行的极小 HTTP 执行端，Tailscale 网段+令牌双重校验、审计日志、手机可用网页控制台）；`rctl.ps1`（电脑端客户端）；`uninstall-remote-access.ps1`（按状态回滚）；`README.md`（现状、执行步骤、验证清单、手机/电脑端配置、安全要点、FAQ）。
- **安全约束**：所有新增防火墙规则仅允许 `100.64.0.0/10`（Tailscale）入站，不做公网映射；WinRM 默认放开的任意来源规则 `WINRM-HTTP-In-TCP-PUBLIC` 被收回；SSH `administrators_authorized_keys` 用 SID 收紧 ACL。
- **验证**：四个脚本通过 PowerShell 语法解析（Parser API 无错误）；Agent 内嵌网页与脚本经抽取后 `node --check` 通过。未实际执行——初始化需管理员 UAC，待用户在场后运行。
