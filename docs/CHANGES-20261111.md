- `ShowAndActivate` 记录实际激活结果，未激活时在 `ApplicationIdle` 补一次 `Activate()`，避免“已显示但未激活”的中间态被误隐。

## 2026-11-11 11:02:29 — fix(clipboard): 托盘菜单内「清空历史记录」改为菜单关闭后再弹确认框

- 根因（实机取证）：托盘右键 → 剪贴板历史 → 清空历史记录时，`MenuItem.Click` 内同步 `MessageBox.Show()`（无 owner）会被菜单 Popup 隐式拥有（`GetWindow(hDlg, GW_OWNER)` 返回菜单 HWND）；菜单窗口关闭销毁 Popup 时，其 owned 对话框一并被销毁，表现为 100~300ms 内“一闪而过”。
- 修复：`ClearAllHistory` 不再同步弹框，改用 `DispatcherTimer` 延迟 250ms，等菜单窗口真正销毁后再创建确认框；托盘菜单与浮窗菜单共用该入口，一并覆盖。确认后才执行 `ClearAll(preservePinned: true)`。
- 验证（真实进程 + 最终构建）：托盘右键 → 剪贴板历史 → 清空历史记录，确认框 300ms 出现，1.5s 后仍可见且 `owner=0`；点「否」`history.json` 保持 372 字节不变；点「是」后写入 `[]`（5 字节）。
- 构建/测试：`dotnet build` 0 警告 0 错误；`dotnet test` **445 通过 / 0 失败 / 0 跳过**。
