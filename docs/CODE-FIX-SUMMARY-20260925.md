# CarroDesk 已实施修复总结

> 总结日期：2026-09-25 16:01（GMT+8）
> 对应代码状态：当前工作区未提交改动
> 关联变更记录：`docs/CHANGES-20260925.md`

## 1. 本轮目标

本轮针对全面代码审查中确认的、会实际影响功能正确性的缺陷，优先处理数据丢失、错误执行、状态机失控、配置假成功和跨线程 UI 操作问题；纯视觉优化、锦上添花功能和大规模架构重构暂不纳入本轮。

## 2. 已实施修复

### 2.1 配置、原子写入和保存结果

- 配置热重载采用候选快照校验后再提交；解析失败、I/O 失败或根节点错误时保留上一份有效配置。
- 首次配置读取遇到文件占用、权限或 I/O 异常时不再静默进入首次 PIN 流程。
- `IConfigManager.SaveModuleConfig` 和 `IConfigManager.Reload` 返回真实结果；调用方可以阻止假成功提示。
- 模块 token 替换、落盘和失败回滚收拢到 `ConfigService` 同一锁内，避免并发保存互相覆盖回滚快照。
- `AtomicFile` fallback 在第二次移动失败时恢复旧文件；启动时尝试从最新 `.bak` 恢复目标文件。
- 配置编辑器、开机自启、模块托盘开关、悬浮面板状态和任务总开关保存失败时回滚内存/运行时状态。

### 2.2 任务计划与脚本调度

- 未知或缺失 `trigger.type` 不再隐式退化为 `startup`。
- 未来 schema 的 `tasks.json` 进入只读保护，旧版本不会把新版文件重建为空数组。
- 任务编辑器发现解析错误时禁止覆盖原文件，避免合法任务保存时删除非法任务。
- 合法 trigger 别名统一映射到规范类型，避免编辑器 round-trip 后变成启动任务。
- 首次启动自动创建 `tasks.json` 和任务样例。
- Cron 增加 UI 阻塞后的补触发、8 年搜索窗口和闰日调度支持。
- 启动延迟增加范围校验，避免整数溢出导致任务永不执行。
- 任务禁用、删除或调度器停止后，不再启动新的重试；后台调用 Reload/启用时统一封送到注入的 UI Dispatcher。
- AC、网络、文件条件探测异常时按限制条件 fail-closed。
- 实现 `{{timestamp}}`，无效显式工作目录不再静默回退执行。

### 2.3 锁屏、PIN 和键盘隔离

- 未配置 PIN 时 `LockSafe` 返回失败，不再把 no-op 当成锁定成功。
- 键盘钩子安装失败时回滚锁屏状态并记录 Win32 错误。
- 闲时触发排队后执行前重新检查用户活动、暂停、会话、模块开关和当前空闲时间。
- 增加 Power Resume 处理，避免睡眠期间闲时状态错误。
- 锁屏 Stop 时解除锁窗、键盘钩子和相关订阅。
- 锁屏、退出和修改 PIN 使用共享的进程级 PIN 限流。
- 损坏 PIN 不再被视为有效配置，允许进入重新设置流程。
- 锁屏期间未明确允许的普通键盘输入默认拦截，避免泄漏到下层窗口。

### 2.4 Awake、音频和剪贴板

- Awake 持久化 `Timed/UntilTime` 有效截止时间，旧配置缺少截止时间时安全回退。
- Awake 总开关、电池暂停、快速切换和设置窗口均增加状态恢复和保存失败回滚。
- 音频默认设备切换要求 Console、Multimedia、Communications 三种角色一致；任一失败时回滚全部角色。
- 检查音频静音 HRESULT，修复音频设备枚举异常时的 COM 泄漏。
- 剪贴板回写失败时不再隐藏窗口或发送全局粘贴；粘贴前验证原目标 HWND。
- 剪贴板事件即时捕获文本，抑制状态增加有效期，损坏历史先备份。
- 防御 `RetentionDays` 越界，配置变更时重算预览，并释放存储资源。
- 剪贴板模块总开关关闭时不再启动自动监听。

### 2.5 模块、托盘和显示器

- 停止的模块不会因配置重载重新启动监听器、计时器、硬件调用等副作用。
- 模块 Start/Stop 增加竞态保护和启动失败清理。
- 动态托盘过滤无效模块，并修复 `yield return` 菜单迭代异常隔离。
- 受管热键注册失败时保留旧热键；裸字符热键默认拒绝，支持 `Ctrl+-`。
- DDC 合并请求返回最终实际应用快照，旧请求不会覆盖新状态。
- 显示器计划只有硬件调用成功后才标记已应用，失败会保留重试机会。
- AutoSchedule 关闭后，Resume/Session 事件不再强制应用计划。
- 显示器延迟任务增加生命周期代数和二次等待校验。
- 修复 MonitorProfile 设置保存失败仍提示成功，以及保存时重置 `Enabled`。
- 悬浮面板支持副屏/负坐标位置恢复，保存失败回滚置顶、锁定和位置。
- 保持系统级 DPI 感知，避免直接把 Win32 物理像素错误地当作 WPF DIP。

### 2.6 其它可靠性修复

- FolderPicker、AutoStartService、音频集合等 COM/Process 资源补充确定性释放。
- 防止未来版本任务文件和损坏历史文件被无提示覆盖。
- 配置错误 PIN、未来 schema、未知 trigger、别名、Cron 闰日、Awake 状态、剪贴板越界等新增回归测试。

## 4. 尚未完全解决的问题

以下问题仍需后续处理，但不应与本轮已完成的修复混淆：

1. **任务进程 Job Object 原子加入**：当前仍是先启动进程再加入 Job；快速启动器可能在加入前创建子进程，彻底修复需要 `CREATE_SUSPENDED` 或独立 worker 进程。
2. **PIN 防重启持久化**：当前锁屏、退出、修改 PIN 已共享进程级限流，但重启进程仍会清空失败次数；真正跨重启限流需要持久化剩余时间或截止时间。
3. **音频设备变化实时通知**：`DevicesChanged` 仍没有接入 `IMMNotificationClient`，设备热插拔只能在下一次查询时刷新。
4. **非默认音频端点进程静音**：当前 AppAutoMute 仍主要扫描默认 Multimedia 端点，非默认 USB/蓝牙/HDMI 端点上的进程可能无法控制。
5. **DDC/WMI 原生调用硬超时**：驱动或显示器异常时，原生调用可能长时间阻塞；需要 worker 隔离、超时和放弃当前操作。
6. **真正混合 DPI 支持**：当前保留系统 DPI 感知以避免物理像素/DIP 混用；完整 Per-Monitor V2 需要统一 Win32 物理坐标和 WPF DIP 转换并实机验证。
7. **锁屏安全边界**：当前仍是普通桌面上的伪锁屏，不能替代 Windows 安全桌面或系统原生锁屏。
8. **低收益体验/工程项**：完整 XAML 国际化覆盖、UI golden image、更多 COM 单元测试、文档菜单路径同步等属于后续工程完善，不是当前最高优先级功能修复。

## 5. 后续建议顺序

1. 先做 DDC/WMI 超时和 PIN 跨重启限流；
2. 再做 Job Object 原子加入；
3. 然后接入音频设备变化通知和全端点会话枚举；
4. 最后处理混合 DPI和安全桌面等需要实机/系统级验证的方案。
