# 变更记录

## 2026-09-24 17:30 — 重构保持唤醒（Awake）进程联动为独立状态并优化状态展示

**背景**：原 Awake 进程联动直接修改用户模式 `_mode = AwakeMode.Indefinite`，导致用户持久化配置被污染、托盘菜单勾选项冲突，且原有联动状态展示易混淆。此外，在用户已手动保持唤醒期间，联动进程进出会发送重复干扰通知。

**进程联动状态解耦（AwakeService）**
- 将进程联动抽离为独立叠加状态 `_isProcessTriggered`，不再篡改用户手动基底模式 `_mode` 与持久化配置文件。
- 引入 `IsProcessExiting` 状态与 `ProcessExitPendingSeconds`，使退出缓冲期状态可感知且透明可追踪。
- 优化进程枚举效率：单次采样全系统进程快照比对，替代循环枚举；修复多目标进程切换时的残留问题。
- 用户手动"关闭"后记录会话抑制，并在守护进程全部退出、手动切换模式、保存设置或重新开启联动时安全复位。
- 配置更新或名单清空时即时撤销正在进行的联动唤醒，消除状态残留。

**菜单与提示呈现优化（AwakeModule / AwakeSettingsWindow）**
- 静默联动：若用户本来就在手动保持唤醒状态（永久或定时），进程进出不弹出气泡通知，避免打扰。
- 托盘根节点与悬浮提示清晰分层：电池暂停 > 用户手动模式（永久/定时） > 进程退出缓冲（含剩余秒数） > 进程联动运行中 > 遵循系统默认关闭。
- 解决菜单勾选冲突：系统处于进程联动时，"关闭"项不再呈现勾选，仅在真正处于 Passive 且无联动时勾选。
- 托盘菜单项 `TrayMenuItem.ToolTip` 补充 `OnPropertyChanged` 通知，支持退出缓冲秒数动态刷新。
- 设置窗口状态徽章支持黄色缓冲倒计时展示，并在保存设置时复位抑制状态。

**测试**：更新并新增 Awake 进程联动隔离与退出缓冲单元测试，全量 186 项测试全部通过。

## 2026-09-24 17:15 — 修复开机自启动路径自愈、异常反馈与启动任务去重

**背景**：审查自启动处理发现便携模式移动目录后注册表残留失效路径无法自愈、可执行文件定位存在 DLL 风险、注册表写入异常被全吞导致 UI 假阳性勾选，以及计划任务模块中 startup 触发器在配置重载时被重复触发。

**自启服务（AutoStartService）**
- 使用 Process.GetCurrentProcess().MainModule.FileName 与 Assembly.GetEntryAssembly() 可靠解析主程序路径并校验磁盘存在性。
- IsEnabled() 增加路径比对：注册表键值存在但路径失效时判定为 alse。
- Sync() 与 SetEnabled() 支持路径自愈，并返回 ool 操作结果。

**界面与反馈（TrayContextMenu / FloatingPanelWindow）**
- 切换自启若被安全软件拦截或写入失败，捕获并提示气泡通知，避免配置与 UI 勾选产生假阳性。

**启动与调度（App.xaml.cs / TaskSchedulerService）**
- App.OnStartup 显式重置 Environment.CurrentDirectory = AppDomain.CurrentDomain.BaseDirectory，避免 Windows 开机拉起时工作目录偏离至 System32。
- TaskSchedulerService 增加启动任务执行记忆 _firedStartupTasks，避免托盘重载配置或保存设置时误重复触发开机延迟任务。
